# **App Name**: Nimbus POS

## Core Features:

- Product & Category Management: Admin panel to add, edit, and categorize products.
- Barcode Scanning: Enables barcode scanning for quick product addition to the cart.
- Cart & Billing: Real-time cart updates and secure billing process.
- Discounts & Tax: Apply discounts and calculate taxes on the total bill.
- Customer Management: Add and manage customer profiles for loyalty programs.
- Inventory Tracking: Track inventory levels and receive low stock alerts.
- Offline Mode & Sync: Enable offline sales with local storage (IndexedDB/Dexie.js) and automatic synchronization upon reconnection.
- AI-Powered Anomaly Detection: Tool to identify unusual sales patterns or discrepancies in transactions using AI algorithms.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) to convey trust and professionalism.
- Background color: Light Gray (#ECEFF1), provides a clean, modern backdrop.
- Accent color: Cyan (#00BCD4), adds a touch of vibrancy to key interactive elements.
- Body font: 'Inter', sans-serif, for clear and readable text throughout the application.
- Headline font: 'Space Grotesk', sans-serif, providing a modern, tech-focused style for headings and titles.
- Use simple, clear icons from a library like Material Icons to represent common actions and categories.
- Implement a responsive layout that adapts seamlessly to different screen sizes (browser, tablet, desktop).
- Subtle animations for transitions and feedback to enhance the user experience.
